# SEO keyword strategy

Principle: start with **long-tail, high-intent** searches where a small new site can rank, with one genuinely useful page per intent. No mass-generated thin pages.

Difficulty is an **estimate** (low / medium / high) based on the type of sites that usually rank (big SEO suites vs small tools). Verify with Google Search Console data after launch, and with a keyword tool (Google Keyword Planner is free with an Ads account) before writing new pages.

## Next pages worth building (one at a time, measure first)
- Mobile-friendly checker, Core Web Vitals checker (once a PageSpeed key is configured), structured data checker, hreflang checker, redirect checker.
- French versions of the 2–3 tools that get English traffic first (real translation, not duplicated content).

## Product SEO already in place
Server-rendered HTML, unique title/description per page, canonical, hreflang EN/FR, Open Graph + Twitter card, JSON-LD (WebApplication, FAQPage), `sitemap.xml`, `robots.txt` (reports and API excluded), shared reports `noindex` to avoid thin pages, fast pages without JavaScript frameworks.

## Off-page (no paid ads, no manual outreach)
- GitHub: open-source core, good README, topics (`seo`, `website-audit`, `crawler`, `accessibility`).
- Discreet "Report generated by AI Website Auditor" on every shared report (organic backlinks when people share reports).
- Listings: Product Hunt, AlternativeTo, awesome-seo lists on GitHub, French dev communities. One launch post each, no spam.
